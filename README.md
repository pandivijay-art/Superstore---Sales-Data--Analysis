# Superstore Sales Data Analysis

## Project Overview

This project analyzes a Superstore Sales dataset using Python. The objective is to perform data cleaning, exploratory data analysis (EDA), data visualization, and generate business insights and recommendations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Data Import
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insights
7. Business Recommendations

## Business Questions Answered

- Which region has the highest sales?
- Which category has the highest sales?
- Which sub-category has the highest sales?
- Which customer segment has the highest sales?
- How do sales change over time?
- Which state has the highest sales?

## Key Insights

- California recorded the highest sales.
- Consumer was the highest-performing customer segment.
- Phones generated the highest sales among sub-categories.
- Sales varied across different months and states.

## Business Recommendations

- Continue successful strategies in high-performing regions and states.
- Improve low-performing states through marketing campaigns and promotional offers.
- Analyze customer behavior to improve sales in low-performing segments.
